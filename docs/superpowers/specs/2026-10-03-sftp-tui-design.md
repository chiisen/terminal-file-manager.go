# SFTP TUI 設計（#13）

目標：以現有 SSH/SFTP API 支援遠端目錄瀏覽、返回上層及串流下載至本機，連線與傳輸不中斷 TUI 事件處理。SSH 主機驗證依 #10；不保存或要求明文密碼，命令列使用私鑰認證。

## 入口及操作

`gofm --remote user@host:/path --port 22 --key <私鑰> --known-hosts <檔案> --download-dir <本機目錄>`；埠預設 22、known_hosts 預設使用者家目錄 `.ssh/known_hosts`，下載目錄預設目前工作目錄。本機模式保留 `gofm [目錄]`，不接受互相衝突的遠端／本機參數。

遠端模式共用導航、搜尋與排序；Enter 開啟目錄，選取檔案按 `Ctrl+D` 下載。`Ctrl+R` 重試／刷新。路徑列標示遠端主機，操作區顯示連線／讀取／下載進度與結果。遠端上傳、修改及預覽不屬於本次範圍，既有本機修改快捷鍵在遠端模式須阻擋。

## 背景流程與生命週期

App 保存遠端 session 與取消 context。Init 的命令建立 SSH/SFTP，完成訊息才更新 session。目錄命令捕捉路徑／請求編號，Update 忽略過期結果。遠端目錄已包含 metadata，不再執行本機 stat 或 Git。遠端使用 POSIX path，下載目的地使用本機 filepath。

連線使用可取消的 TCP 撥號，握手及 SFTP 初始化有 15 秒期限；退出取消 session、關閉連線，使未完成工作結束。失敗可刷新重試，錯誤只包含主機／路徑與原因，不包含密碼或私鑰內容。背景完成訊息不得修改 Model。

## 下載一致性

一次下載一個普通檔案，繁忙時阻擋重複下載；導航仍可使用。目的地已存在時拒絕覆寫。拒絕跨平台不安全檔名，下載至本機目錄內唯一暫存檔，成功關閉後以不覆寫的方式發布；任何讀取／寫入／發布錯誤皆清除暫存並回報失敗。使用既有固定 32KB Download 串流，不累積整份檔案。

## 驗證

CLI 設定／衝突／無效輸入測試；真實 SSH/SFTP 本機伺服器驗證金鑰認證、遠端 metadata 與下載。可控制的慢速連線／目錄／下載事件測試驗證 UI 回應、過期結果、錯誤顯示、重複阻擋與取消。檔案測試涵蓋成功、已有目的檔、部分傳輸錯誤、不安全名稱及暫存清理。全套 test、vet、race、build 及 diff 檢查通過後，更新 README／TODO／CHANGELOG，提交、推送並關閉 #13。
