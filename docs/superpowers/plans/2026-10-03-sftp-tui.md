# SFTP TUI 實作計畫

> 執行方式：依使用者「完成全部任務並 commit+push」授權，由目前 agent 直接執行，沿用測試先行與逐項交付。

**Goal:** 完成 #13 的遠端瀏覽與串流下載入口。
**Architecture:** CLI 解析設定，App 背景命令建立與使用 remote session，由 Update 更新畫面；下載暫存後發布。
**Tech Stack:** Go、Bubble Tea、x/crypto/ssh、pkg/sftp；不新增依賴。
**Spec:** [設計](../specs/2026-10-03-sftp-tui-design.md)

## 全域限制

Windows PowerShell 與 Linux 相容；遠端 POSIX 路徑；不儲存明文密碼；主機金鑰預設驗證；不覆寫本機既有檔案。

## 檢查重點

未知金鑰拒絕；慢速握手可取消；舊目錄結果不覆蓋新位置；遠端名稱不能越界或變成 Windows 裝置；失敗下載不留下完成檔。
